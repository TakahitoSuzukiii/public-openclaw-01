# 貞観政要 ― 1400年前の「リーダーの自制と傾聴」を日常に取り込む実践ガイド

> 概要: 唐の名君・太宗と側近たちの問答をまとめた『貞観政要（じょうがんせいよう）』を、現代の仕事・チーム・自己管理にそのまま使える習慣に翻訳した実践ノート。核心は「トップが自分を律し、耳の痛い意見を歓迎する」こと。

- **これは何**: 中国・唐の二代皇帝 **太宗（李世民）** と、諫（いさ）め役の **魏徴（ぎちょう）** ら側近の対話集。編纂は呉兢（ごきょう）。「貞観の治」と呼ばれる名君政治の記録で、**帝王学（リーダー論）の最高峰**とされる。徳川家康・北条政子・明治天皇らも愛読した。
- **一番の核**: 力（実績）だけでは足りない。**リーダーが自分を戒め、耳の痛い進言を歓迎し、複数の声を聞く**ことで組織は長く安定する。
- **対象読者**: 立場に関わらず「自分を律し、良い判断を続けたい」人。チームや上司・部下と関わる人。

---

## 1. 太宗と魏徴 ― なぜ名君政治が生まれたか
- 太宗は武力で唐を安定させた実力者。だが彼のすごさは **「耳の痛いことを言う魏徴を重用し、諫言を受け入れ続けた」** 点にある。
- 魏徴はもともと敵陣営にいた人物。太宗は過去を問わず登用し、300回以上も諫められたと伝わる。
- 魏徴の死に太宗はこう嘆いた ―「**人を以て鏡と為せば、以て得失を明らかにすべし**」。自分の欠点を映してくれる鏡を失った、と。

> ここが本書の背骨。**トップが「自分に反対する人」を横に置き続けた**からこそ、暴走せず名君でいられた。

## 2. 日常に効く4つの原理と「今日からの実践」

### ① 創業と守成、いずれか難き（守成篇）
- **問答**: 太宗が問う「国を興すのと、維持するの、どちらが難しい？」。答えは分かれるが、結論は **「守成（維持）こそ難しい」**。立ち上げは勢いでできるが、成功後に**気の緩み・慢心**で崩れる。
- **日常訳**: 新しく始めるより、**良い状態を保ち続ける**方が難しい。
- **エンジニア/仕事例**: 立ち上げた仕組み・習慣・品質を、成功後に**慢心せず維持**する（運用・保守こそ本番）。ダイエットや学習習慣も同じ。
- **今日から**: 「もう出来ている」と思う領域ほど、月1で点検する。

### ② 明君は兼聴（けんちょう）し、暗君は偏信（へんしん）す（君道篇）
- **意味**: 良い判断をする人は **複数の声を広く聞く**。ダメな人は **一つの情報源だけを信じる**。
- **日常訳**: 一人の意見・一つのソースで決めない。**反対意見をわざと探す**。
- **エンジニア例**: 設計判断は複数人にレビューを依頼。エコーチェンバー（同意見だけの環境）を避ける。
- **今日から**: 重要な判断の前に「これに反対する人なら何と言うか？」を1つ書き出す。

### ③ 諫言（かんげん）を歓迎する
- **意味**: 太宗は、耳の痛い進言をする部下を**罰せず、むしろ賞した**。批判者を遠ざければ裸の王様になる。
- **日常訳**: **自分の間違いを指摘してくれる人は最重要人物**。感謝で返す。
- **エンジニア例**: コードレビューの指摘・レビュアーへの向き合い方そのもの。指摘に防御的にならず「ありがとう」で受ける文化＝現代版の諫言歓迎。
- **今日から**: 誰かに指摘されたら、反論の前にまず「指摘してくれてありがとう」と言う。

### ④ 感情で賞罰を決めない（十思より）
- **意味**: 嬉しさで過大な褒美を、怒りで過剰な罰を与えない。**感情と評価を切り離す**。
- **日常訳**: 機嫌で判断がブレないよう、**一拍おいてから決める**。
- **今日から**: 感情が動いた直後の重要な返信・評価は、**一晩寝かせる**。

## 3. リーダーの自己点検「十思（じゅっし）」
魏徴が太宗に贈った、リーダーが常に思い返すべき **10の心得**（君道篇）。役職に関係なく「自分を律するチェックリスト」として使える。

| # | 教え | 現代の自己点検 |
|---|---|---|
| 1 | 足るを知る | 欲しい物が出たら「もう十分では？」と一拍おく |
| 2 | 人を安んず | 大事業の前に、周囲に休息・余白を与えているか |
| 3 | 謙沖に自ら牧う | 危ない橋を避け、実力を過信しない |
| 4 | 江海は百川に下る | 傲慢を恐れ、低い姿勢で人の流れを集める |
| 5 | 三駆を度とす | 楽しみ・追い込みにも限度を設ける |
| 6 | 始めを慎み終わりを敬す | だれた時こそ初心を思い出し、やり切る |
| 7 | 心を虚しくして下を納る | 耳をふさがず、下の声を聞く |
| 8 | 身を正して悪を黜（しりぞ）く | そしられぬよう自分を正す |
| 9 | 賞を謬（あやま）る無し | 喜びで過大な褒美を与えない |
| 10 | 刑を濫（みだり）にする無し | 怒りで過剰な罰を与えない |

> 使い方: 毎朝この10個を眺め、今日の自分に一番効くものを1つ選ぶ。特に **7（傾聴）・9・10（感情で賞罰しない）** は現代の仕事で刺さる。

## 4. 人格の九徳（きゅうとく）― 相反する2つのバランス
『書経』由来で貞観政要にも通じる、リーダーの資質「九徳」。**各徳が「相反する2つの性質の両立」**になっているのが肝。自分の偏りを直す指針になる。

1. 寛にして栗 … 寛大だが締まりがある
2. 柔にして立 … 柔和だがテキパキ進む
3. 愿にして恭 … 厳しいが丁寧で横柄でない
4. 乱にして敬 … 事を収める力があるが慎み深い
5. 擾にして毅 … 穏やかだが芯は毅然
6. 直にして温 … 率直だが人あたりは温和
7. 簡にして廉 … 大まかだが筋は通す
8. 剛にして塞 … 強い意志だが押しつけず思慮深い
9. 彊にして義 … 実行力があるが暴走しない

> **1か月に1つ**を意識して実践 → 9か月で一巡、を何度も繰り返すのが古来の使い方。自分が「陰（寛・柔・穏）」寄りか「陽（栗・立・毅）」寄りかを見て、**足りない側**を補うとよい。逆（例:「寛にして栗」の逆＝こせこせうるさいのに締まりがない）を考えると意味が掴める。

## 5. 「今日から」の取り込み方（習慣化）
- **毎朝（1分）**: 十思を眺め、今日効く1つを選ぶ。
- **判断の前**: 「反対する人なら何と言う？」を1つ書く（兼聴）。
- **指摘されたら**: まず「ありがとう」。防御は後（諫言歓迎）。
- **感情が動いたら**: 重要判断は一晩寝かせる。
- **毎月**: 九徳から1つを選んで実践。成功して慢心しかけた領域を点検（守成）。
