# 孫子の兵法 ― 「戦わずして勝つ」を日常に取り込む実践ガイド

> 概要: 2500年前の兵法書『孫子』を、現代の仕事・意思決定・人間関係・キャリアにそのまま使える「行動のルール」に翻訳した実践ノート。名言の意味だけでなく「今日から何をするか」まで落とし込む。

- **これは何**: 中国・春秋時代の武将 孫武（そんぶ）が著したとされる、全13篇の戦略書。テーマは「どう戦うか」ではなく **「いかに戦わずに目的を達するか」**。軍事を超え、経営・交渉・スポーツ・キャリアに応用され続けている。
- **一番の核**: 「百戦百勝は善の善なる者に非ず。**戦わずして人の兵を屈する**は善の善なる者なり」（謀攻篇）＝ 勝ち続けることより、**そもそも消耗戦を避けて勝つ**のが最上。
- **対象読者**: 日々の意思決定・仕事の進め方・転職活動に、古典の原理原則を効かせたい人。

---

## 1. まず全体像（13篇を3行で）

孫子は「いきなり戦い方を語らず、**戦う前の計算**から入る」構成になっている。全部を覚える必要はなく、次の流れだけ掴めばよい。

1. **戦う前**（計篇・作戦篇・謀攻篇）… 勝敗は始める前の準備でほぼ決まる。消耗戦は避ける。
2. **動くとき**（軍争篇ほか）… 有利な位置を先に取り、状況で動きを変える（風林火山）。
3. **情報**（用間篇）… 敵情を知るために情報（間者＝スパイ）に投資する。

> ポイント: 孫子では **城攻め（真正面の力押し）が最低ランクの手段**。「頭を使って、戦う前に勝て」が一貫した思想。

## 2. 日常に効く5つの原理と「今日からの実践」

### ① 彼を知り己を知れば、百戦殆（あや）うからず（謀攻篇）
- **意味**: 相手だけでなく **自分の力も正しく把握**すれば危険はない。続きがあり「己だけ知る＝五分五分、両方知らない＝毎回危険」。
- **日常**: 会議・交渉・面接の前に「相手の状況」と「自分の手札」を紙に書き出す。
- **キャリア（転職）**: 志望企業の研究（事業・文化・求める人物像）＝彼を知る。自分の強み・弱み・市場価値の棚卸し＝己を知る。**両方揃って初めて勝率が上がる**。
- **今日から**: 重要な打ち合わせの前に3分、「相手が欲しいもの／自分が出せるもの」を箇条書き。

### ② 勝ってから戦う（先（ま）ず勝ちて而（しか）る後に戦いを求む・形篇）
- **意味**: 強い者は **勝てる状況を作ってから**動く。弱い者は戦い始めてから勝ちを探す。
- **日常/仕事**: 「やってみて考える」の前に、**勝ち筋（成功条件）が見えてから着手**する。
- **エンジニア例**: いきなり実装せず、要件・制約・検証方法を固めてから書く。PoC で勝ち筋を確認 → 本実装。
- **今日から**: タスク着手前に「これが満たせれば成功」という条件を1行決める。

### ③ 兵は拙速（せっそく）を聞く（作戦篇）
- **意味**: 戦争は金も人も消耗する。**多少雑でも速く**が、完璧を狙った長期戦に勝る。
- **日常**: 完璧主義で抱え込むより、**60点で早く出して直す**。長引く案件は損。
- **エンジニア例**: 大きな一発より、小さく出して検証（MVP・追加のみ）。※ただし「拙速＝手抜き」ではなく「早く価値を出して修正回数を稼ぐ」の意。
- **今日から**: 「これは完璧を目指すタスクか、速さ優先か」を最初に仕分ける。

### ④ 戦わずして勝つ（謀攻篇）
- **意味**: 最善は、**そもそも争いが起きない状況**を作ること。
- **日常/人間関係**: 議論で言い負かすより、**対立が生じない設計**をする（事前の根回し、期待値のすり合わせ）。
- **ビジネス**: ライバルと消耗戦をするより、**棲み分け・共存**で勝つ。
- **今日から**: もめそうな案件は「勝つ」より「もめない段取り」を先に考える。

### ⑤ 風林火山（軍争篇）＝ 状況で速度を変える
- **意味**: 「疾（はや）きこと風の如く、徐（しず）かなること林の如く、侵掠（しんりゃく）すること火の如く、動かざること山の如し」。**局面ごとに振る舞いを変える**柔軟さ。
- **日常**: 常に全力ではなく、**攻める時・待つ時・動かない時**を意識的に切り替える。
- **今日から**: 今の案件は「風（即動）／林（静観）／火（一気）／山（不動で待つ）」のどれか、を毎朝1つ選ぶ。

## 3. 意思決定チェックリスト「五事（ごじ）」
孫子は開戦前に、自分と相手を **5つの観点**で比較せよと説く（計篇）。これは重要な意思決定の汎用チェックリストとして使える。

| 五事 | 原義 | 現代の問い（自分に当てはめる） |
|---|---|---|
| **道** | 大義・人心 | この選択に納得感・目的の一致はあるか？ |
| **天** | 天候・タイミング | 時期・タイミングは合っているか？ |
| **地** | 地形・環境 | 自分に有利な土俵か？場所・環境は？ |
| **将** | 将の力量 | 遂行する人（自分/リーダー）の力量は足りるか？ |
| **法** | 制度・仕組み | 仕組み・ルール・段取りは整っているか？ |

> 転職の意思決定にそのまま使える: 道＝働く目的と合うか / 天＝今動くべき時期か / 地＝自分が活きる環境か / 将＝やり切れるか / 法＝選考や生活の段取り。

## 4. 情報への投資 ―「用間（ようかん）」
- 孫子は最終篇を **情報（間者の活用）** に割いた。「敵情を知るのに金を惜しむ者は、勝利を捨てているに等しい」という立場。
- **日常訳**: 大事な判断ほど、**情報収集にコストをかける**のは合理的。
- **キャリア例**: 口コミ・現場の人の話・一次情報を取りにいく（給与・文化・実態）。情報の非対称を埋めるほど失敗が減る。

---

## 5. 「今日から」7日間の取り込み方（習慣化）
1. **月**: 重要タスクの前に「彼/己」メモ（3分）。
2. **火**: 着手前に「成功条件1行」を書く（勝ってから戦う）。
3. **水**: 全タスクを「完璧型／拙速型」に仕分け。
4. **木**: もめそうな件を「もめない段取り」で設計。
5. **金**: 今週の案件を風林火山で1つ分類。
6. **土**: 大きな決定を「五事」でチェック。
7. **日**: 来週の判断材料（情報）を1つ取りにいく。
