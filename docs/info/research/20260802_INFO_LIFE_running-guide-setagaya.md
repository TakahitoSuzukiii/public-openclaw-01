# ランニング スタートアップガイド（世田谷・三軒茶屋エリア）

> 対象: 久しぶりに走り始める初心者。**続けやすさ・達成しやすさを最優先**。
> 拠点は公共のランドマーク（三軒茶屋駅／蛇崩川緑道／駒沢オリンピック公園／多摩川河川敷）を基準にしています。
> 夏場のため、**涼しい川沿い・緑道（木陰・信号少なめ）を優先**。走るのは早朝がおすすめ。

## 基本方針

- **涼しさ優先**: 川沿い・暗渠（あんきょ）緑道を選ぶ。木陰が多く、信号が少なく、車が入らないので初心者でも安全。
- **無理しない**: 目標は「3か月で5kmを止まらず走れる」。ゆっくりでOK、達成が最優先。
- **週末ベース**: 土日の2回（片方だけでも可）。
- **夏の鉄則**: 早朝 or 日没後に走る。日中の炎天下は避ける。水分携帯、猛暑日は迷わず休む/短縮。

---

## 距離別おすすめコース

いずれも川沿い・緑道中心の涼しめルート。距離は片道/周回の目安。

### 1km — 蛇崩川緑道（じゃくずれがわりょくどう）ミニ
- 上馬〜三軒茶屋方面へ続く暗渠の緑道。木陰と桜並木、信号ほぼなし・車なし。
- 緑道を **片道500m進んで折り返し**＝往復1km。最初の一歩に最適。

### 2km — 蛇崩川緑道ショート
- 同じ緑道を **片道1km進んで折り返し**＝2km。フラットで走りやすい。

### 3km — 蛇崩川緑道フル
- 蛇崩川緑道は全長 **約3km**（下馬〜三軒茶屋・上馬〜弦巻）。緑道を端まで走るコース。
- 信号がないので止まらず走る練習に向く。

### 5km — 駒沢オリンピック公園 周回
- 公園内に **1周2.14km** のランナー専用ジョギングレーン（100mごと距離表示・フラット・信号なし）。
- **2周（約4.3km）＋緑道で往復**＝約5〜6km。ペース管理の練習に最適。

### 7km — 駒沢公園＋緑道ロング
- 蛇崩川緑道 or 烏山川緑道で公園まで行き、公園を **2〜3周** して緑道で戻る構成。
- 烏山川緑道は世田谷を横断する長い緑道で、距離を伸ばしやすい。

### 10km — 多摩川河川敷（二子玉川）※ステップアップ
- 開けた河川敷の定番ランコース。信号ゼロ・見晴らし良好・涼しい。
- 距離が走れるようになったら、ここを本拠地に。**河川敷を片道5km→折り返し10km**。
- アクセス: 田園都市線で二子玉川へ。慣れたら最寄りからラン＋河川敷の組み合わせも。

## 3か月・週末ランニング計画（ウォークラン方式）

**やり方**: 「ジョグ（ゆっくり走る）」と「歩き」を交互に。ペースは**会話できる速さ**が正解。
**頻度**: 土日の2回（同じメニューを両日）。片方しかできなくてもOK。
**ルール**: きつければ同じ週をもう1週くり返してよい。雨・猛暑日は休む。前後に5分ウォーミング/クールダウンの歩き。

### 第1月（Week 1〜4）— 体を慣らす
| 週 | メニュー（1回分・約25〜30分） |
|---|---|
| W1 | ジョグ1分 → 歩き2分 を **5セット** |
| W2 | ジョグ1分 → 歩き2分 を **6セット** |
| W3 | ジョグ2分 → 歩き2分 を **5セット** |
| W4 | ジョグ3分 → 歩き2分 を **4セット** |

### 第2月（Week 5〜8）— つなげる
| 週 | メニュー |
|---|---|
| W5 | ジョグ5分 → 歩き2分 を **3セット** |
| W6 | ジョグ8分 → 歩き2分 を **3セット** |
| W7 | ジョグ10分 → 歩き2分 → ジョグ10分 |
| W8 | **連続20分ジョグ**（約2.5〜3km・ゆっくり） |

### 第3月（Week 9〜12）— 5kmへ
| 週 | メニュー |
|---|---|
| W9  | 連続25分（約3km） |
| W10 | 連続30分（約3.5〜4km） |
| W11 | 連続35〜40分（約4.5km） |
| W12 | **5km 止まらず**（ゴール！ゆっくりでOK） |

> 目安として、W8以降は駒沢公園の周回コースに切り替えると距離が測りやすい。

## 続けるためのコツ

- **ハードルを下げる**: 「今日は10分でいい」でも走れば勝ち。ゼロにしないことが最重要。
- **記録する**: スマホのランアプリ or カレンダーに○をつけるだけでもモチベになる。
- **ウェア/シューズ**: クッションのあるランニングシューズだけは用意する（ケガ予防）。
- **夏の持ち物**: 水/スポドリ、キャップ、日焼け止め。早朝でも熱中症に注意。
- **痛みが出たら休む**: 特にヒザ・すね。休養も練習のうち。

## ステップアップ（河川敷デビュー）
- 5kmを走れるようになったら、**多摩川河川敷（二子玉川）** を定番コースに。
- 開けて涼しく、距離表示や給水スポットも多い。10km・ハーフへの土台に最適。
